1. Show the problem Qurly solves

## 🎥 Recording Tips

### Before Recording
- [ ] Clear browser cache and cookies
- [ ] Close unnecessary tabs and applications
- [ ] Use incognito/private mode for clean demo
- [ ] Prepare test account (email + password)
- [ ] Prepare Shopify product URL (test it first!)
- [ ] Test Gemini API (ensure it's working)
- [ ] Practice the script 2-3 times

### During Recording
- [ ] Use 1920x1080 resolution (Full HD)
- [ ] Record at 30 FPS minimum
- [ ] Use clear, enthusiastic voice
- [ ] Speak at moderate pace (not too fast)
- [ ] Pause briefly between scenes
- [ ] Show mouse cursor for clarity
- [ ] Zoom in on important details (optional)

### After Recording
- [ ] Trim any mistakes or long pauses
- [ ] Add intro slide (project name, tagline)
- [ ] Add outro slide (thank you, links)
- [ ] Add background music (optional, keep it subtle)
- [ ] Add captions/subtitles (optional but helpful)
- [ ] Export as MP4 (H.264 codec)
- [ ] Keep file size under 500MB
